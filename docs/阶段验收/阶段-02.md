## 功能核对

- 简短与复杂中文提交后原话完整，可修改再提交；预期保留中文、标点、emoji、中英混排和换行；实际短句、复杂多行文本、剪贴板粘贴文本和编辑后的第二版均逐字保留；证据：浏览器流程记录与本页测试记录。
- 空白、超长、重复点击有反馈，不丢用户原话；预期空白/纯空格换行不能提交但内容保留，3000 字以上不能提交但内容保留，快速双击只创建一版；实际纯空白输入保留并提示“请先写下你的旅行想法”，3001 字输入保留并提示“内容过长：当前 3001 字，最多 3000 字”，双击后当前草稿区数量为 1 且草稿文本正确；空白响应约 369ms，超长响应约 341ms，页面未卡死。
- 输入法回车不误提交；预期合成状态中的 Enter 不提交，结束合成后的 Enter 可提交，Shift + Enter 可换行；实际 Chrome DevTools `Input.imeSetComposition` 在真实 Chrome 输入管线中生成 `isComposing: true` 的 Enter，草稿保持基线不变；取消合成后普通 Enter 提交成功；Playwright 键盘检查确认 Shift + Enter 插入换行。此检查验证浏览器事件语义，不等同于逐个测试用户安装的具体输入法。
- 示例填入与编辑重提可用；预期示例填入后可直接修改并提交，草稿可放回输入框继续编辑；实际点击“填入示例”后输入框包含多行示例，点击“继续修改并重新提交”后修改内容并再次提交成功。
- 临时草稿边界诚实；预期显示原始文本、临时草稿标识和更新时间，不宣称保存或生成行程；实际草稿区显示原话、`draft-*` 标识和更新时间，并明确“只保留在本次页面会话中，刷新后不会恢复；尚未保存到本机，也没有生成行程”；提交后刷新页面，草稿数量为 0、输入框为空、空态恢复且没有“已保存到本机”声明。
- 不调用 AI、不持久化；预期本阶段仅做客户端表单状态和原话草稿；实际对 `app` 目录执行网络与存储调用扫描，未发现 `fetch`、`axios`、`XMLHttpRequest`、`EventSource`、`localStorage`、`sessionStorage` 或 `indexedDB` 调用；未新增服务端接口或数据库。
- 响应式布局可读；预期 390/768/1440px 无横向溢出且输入区可用；实际内容宽度分别为 390/753/1425px，`scrollWidth` 均不大于内容宽度，输入框和提交按钮均存在；证据：[手机截图](证据/阶段-02-手机-390px.png)、[平板截图](证据/阶段-02-平板-768px.png)、[桌面截图](证据/阶段-02-桌面-1440px.png)。
