## 功能核对

- 首次密码、登录与退出：预期首次只能在本机设置个人密码，之后敏感设置必须验证；实际浏览器完成首次设置、正确密码登录、错误密码拒绝、退出后接口返回 401；证据：浏览器测试记录。
- AI 基本连接：预期页面可配置 Provider、Base URL、API Key、模型，测试通过后才能保存；实际本机模拟 OpenAI-compatible Chat Completions 端点返回文本，测试令牌绑定当前配置指纹，修改后无法保存；证据：[阶段-04-persistence.json](证据/阶段-04-persistence.json)。
- 连接测试防滥用：测试不再使用“你好 / hello / 连接正常”等固定热词，而是生成一次性 `SRD-xxxxxxxx` 校验码并要求模型原样返回；证据：单元、浏览器与集成测试均通过。
- 上游格式与模型列表：预期支持 Chat Completions、Responses、Anthropic Messages 三种格式，并在填写 URL 和 Key 后可获取模型列表；实际三种格式的请求构造和响应解析均已接入，模型列表接口返回模型 ID，页面选择后自动填充模型输入框；证据：浏览器测试记录与[阶段-04-persistence.json](证据/阶段-04-persistence.json)。
- 失败保护与错误诊断：预期错误 Key、模型不存在、超时、无响应不破坏旧配置；实际分别归类为 auth、model、timeout、network，保存令牌不匹配时旧配置保持不变；证据：单元测试与[阶段-04-persistence.json](证据/阶段-04-persistence.json)。
- 密钥安全：预期密钥不进入浏览器、接口输出、日志或明文数据库；实际页面和 `/api/settings` 均不返回密钥，数据库中为 AES-256-GCM 密文，接口日志只记录错误类型；证据：[阶段-04-persistence.json](证据/阶段-04-persistence.json)、[阶段-04-visual-check.json](证据/阶段-04-visual-check.json)。
- Prompt 高级选项：预期基础/系统 Prompt 可编辑、恢复默认前可撤销、保存后不改写旅行；实际保存后版本递增，恢复默认与撤销可用，既有 Trip 原话逐字不变；证据：浏览器测试记录。
- 会话与远程边界：预期非回环访问使用同一密码保护全站，敏感修改带 CSRF；实际远程无 Cookie API 返回 401，伪造 Cookie 的 API 返回 401、页面重定向到设置页；明文 HTTP 登录返回 400；连续 6 次错误密码第 6 次返回 429；证据：[阶段-04-persistence.json](证据/阶段-04-persistence.json)。
- 持久化：预期密码哈希、加密密钥、Prompt、连接摘要和应用重启后仍可用；实际测试库停止再启动后配置与 Prompt 均恢复；证据：[阶段-04-persistence.json](证据/阶段-04-persistence.json)。
- 视觉检查：预期 390、768、1440px 均可读、无横向溢出且截图非空白；实际三档检查全部通过，页面源码不含测试密钥；证据：[手机](证据/阶段-04-设置-手机-390px.png)、[平板](证据/阶段-04-设置-平板-768px.png)、[桌面](证据/阶段-04-设置-桌面-1440px.png)、[阶段-04-visual-check.json](证据/阶段-04-visual-check.json)。
