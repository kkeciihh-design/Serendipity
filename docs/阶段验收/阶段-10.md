- 状态展示：日程卡片显示“来源待确认/已核验/需复核”；选中日程后可查看开放时间、预约要求、价格、位置四个字段；来源抽屉展示状态、查询时间、来源标题、发布方、来源内容日期、建议复核截止、正文摘录、冲突原因和官方入口。实际：通过；证据：[手机截图](证据/阶段-10-来源核验-手机-390px.png)、[平板截图](证据/阶段-10-来源核验-平板-768px.png)、[桌面截图](证据/阶段-10-来源核验-桌面-1440px.png)。
- 搜索摘要不能自动升级：只有实际读取匹配官方域名的页面正文并提取到字段值时才保存 `verified`；搜索结果无官方页面、页面读取失败或字段不匹配时保存/返回 `unverified`，界面显示“建议确认”。实际：通过；测试：`tests/evidence.test.ts`、`tests/evidence-service.test.ts`。
- 旧通知与不同日期：来源发布日期早于行程超过一年，或晚于行程日期时，不标已核验并显示待确认原因；官方闭馆通知没有开放时间值时不会变成已核验。实际：通过；测试：`tests/evidence.test.ts`。
- 来源冲突：同一官方域名下多个实际读取页面提取到不同值时保存 `conflict`；刷新已核验字段时新旧值不同也保存 `conflict`。实际：通过；测试：`tests/evidence.test.ts`、`tests/evidence-service.test.ts`。
- 网络失败保护：来源读取失败时，已有 EvidenceFact 的来源 URL、正文摘录和原状态保留，只记录 `lastRefreshStatus=failed` 和错误信息，界面有效状态降为“已过期/需复核”；没有旧证据时不创建假核验记录。实际：通过；测试：`tests/evidence-service.test.ts`。
- 提示注入隔离：外部 HTML 中的 script/style 被剥离，摘录作为纯文本渲染；页面中的“忽略规则”类文字不会执行，也不会改变业务规则。来源读取限制协议、端口、凭证、本机/内网地址、DNS 解析、重定向、大小、超时和内容类型。实际：通过；测试：`tests/evidence.test.ts`、`tests/evidence-service.test.ts`。
- 用户确认与估算分离：安排状态沿用事件 `suggested/confirmed`，费用确定程度沿用 `estimated/pending_confirmation/user_confirmed`；EvidenceFact 不覆盖这些用户确认或估算状态。实际：通过；测试与浏览器回归通过。
- 计划版本一致性：EvidenceFact 绑定具体 PlanVersion、事件和字段；普通日程或费用编辑生成 V+1 时，仍存在事件的证据被继承；被移除事件的证据不继承；历史版本证据只读。实际：通过；测试：`tests/evidence-service.test.ts`。
- 设置页：新增“来源搜索”，提供 DuckDuckGo 提供方与 English/中文搜索语言配置；测试通过后才能保存；设置接口保持个人密码会话和 CSRF 保护。实际：通过；测试：`tests/evidence-service.test.ts`、`tests/e2e/settings.spec.ts`。

## 修复及复测

- SQLite 迁移最初因父表 `ALTER TABLE ... ADD CONSTRAINT` 语法不支持而失败；删除两条不必要的父表约束（子表 EvidenceFact 已含外键），将失败迁移标记为已回滚并重新应用。复测迁移通过。
- 开放时间提取最初不识别未补零的 `9:00`；已放宽小时格式并复测通过。
- 来源 URL 校验最初只阻止内网域名，未同步阻止 IP 字面量；已增加 IPv4 私网地址校验并复测。
- 搜索设置保存在 AppSettings 记录尚未初始化时会失败；已先确保设置记录存在，并加入集成测试。
- 来源抽屉将候选/失败链接误称为“实际读取来源”；已改为“来源记录”，并按 verified/conflict/unverified 明确说明是否读取到可核验正文。
- 同一官方域名多页面值冲突最初只比较新旧刷新；已改为同次读取多个官方页面时也检测冲突。
- 旧响应式浏览器测试依赖“列表第一条”，并行删除测试会使其打开已删除旅行；已改为按本用例专属标题定位，最终 17 条浏览器测试稳定通过。
- 阶段10验收脚本增加真实来源快照、截图非空白像素检查和证据文件输出，最终复测通过。
