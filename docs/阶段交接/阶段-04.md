## 本阶段新增或改变的数据/接口约定

- `AppSettings` 单例表包含密码哈希/盐、Provider、Base URL、模型、API Key 密文和末 4 位、Prompt 版本与内容、连接状态摘要。接口永不返回 API Key 明文。
- `POST /api/settings/password`：仅本机首次设置，成功后创建会话和 CSRF Cookie。
- `POST /api/settings/session`：验证密码；`DELETE` 退出。远程明文 HTTP 拒绝，连续错误密码触发 15 分钟限流。
- `GET /api/settings`：需有效会话，返回脱敏设置。
- `POST /api/settings/test`：需会话和 CSRF，用临时配置执行 Chat Completions 文本测试，不落库。
- 连接测试使用一次性 `SRD-xxxxxxxx` 校验码，避免固定问候语被公益站点识别为批量探活。
- `POST /api/settings/models`：需会话和 CSRF，按当前 Provider/Base URL/Key 获取模型列表，不落库；支持 Chat Completions、Responses、Anthropic Messages。
- `POST /api/settings`：需会话、CSRF 和与当前配置指纹匹配的 30 分钟测试令牌；失败或不匹配时旧配置不变。
- `PATCH /api/settings/prompt`：需会话和 CSRF，保存基础/系统 Prompt；内容变化时版本递增，不改写 Trip。
- Cookie：`serendipity_session` 为 HttpOnly 签名会话，`serendipity_csrf` 供敏感请求头 `x-csrf-token` 校验。
- 远程访问：非回环地址下，页面和 Trip API 均要求同一有效会话；本机回环下旅行功能保持可用，设置仍受密码保护。
- AI 请求限制：仅 HTTPS，或明确回环 HTTP；15 秒超时、禁跳转、1MB 响应上限。
