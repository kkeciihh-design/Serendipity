## 实现与接口

- `lib/places.ts`：Place/Candidate schema、稳定 ID、坐标转换。PlanVersion 新 `places` JSON（默认空数组）；PlanEvent 新可选 `placeId`。沿用总文档允许的计划快照，不另建不必要的 Place 表。旧版本保持无坐标，不迁移猜测位置。
- Place 保存 provider、POI ID、名称/城市/完整地址、原坐标及坐标系、精度、查询/确认时间和来源。`osm:<type>:<id>:<precision>` 或 `amap:<poi>:<precision>`；同地点多次到访复用 ID，但事件 ID 独立。精确 POI 与区域参考具有不同身份。
- 免费服务：`lib/osm.ts`，固定 HTTPS Nominatim `/search`，手动查询、串行节流、缓存和超时/大小限制。国内城市从完整地址补出明确的“市”，保留区字段；无结果不造坐标。缓存目录是数据根的 `map-search-cache`，最多约 500 项，24h TTL。
- `lib/map-service.ts` 搜索/确认；候选签名绑定 tripId/version/eventId/到期时间。`POST /api/trips/:id/plans/:version/places` 搜索；`PATCH` 确认候选或显式清除引用。沿用统一来源保护。新增版本中费用、需求快照、待确认项保持原依据；相关证据按 placeId 变化降级。保护锁定/确认事件，重生成保护已确认地点。
- `app/components/plan-map.tsx` 地图页签、日期/城市筛选、等价文字列表、候选确认；`map-canvas.tsx` 用同源 iframe 隔离地图 SDK，只接收正确 origin/source 的消息；`app/map/frame` 默认懒加载 Leaflet，按原坐标系转换到当前底图坐标后标点。未实现编号/路线。
- `/api/map/config` 免费模式仅返回 `{provider:"osm"}`。地图瓦片遵循浏览器正常缓存，带来源署名；不做批量预取和离线下载。视口变化重新 fitBounds；瓦片全部完成后再报可用；失败可重试并保留文字行程。
- 地图设置位于同一密码保护设置页。`GET/POST /api/settings/map`、`POST /api/settings/map/test`；默认 provider=OSM，切回免费模式保留但不启用旧高德配置。
- 可选高德：`lib/amap.ts` / `lib/map-settings.ts` / `lib/map-proxy.ts`。三个 Key 分型加密；临时测试配置用有时限的 HttpOnly 加密 cookie，不回传服务端密钥。JS 底图代理在 `/api/map/[...path]` 实现，接受 `/_AMapService` 或 `/preview/_AMapService` 前缀。**不要改回以下划线命名的 Next 文件夹，Next 会把它作为私有目录忽略。** 代理仅允许 `/v4/map/styles` 和 `/v3/log/init`，固定目的域名、覆盖 Key、安全密钥、过滤回调、限体/限时/禁跳转。未来真实接高德时需按账号和 SDK 实测调整最小白名单，当前没有宣称真实授权通过。
