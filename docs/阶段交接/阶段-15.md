## 入口与实现

- 正式：[旅行列表](http://127.0.0.1:3003/trips)。进入计划后总览置顶红线，时间轴“查看时间红线”可跳转。门到门交通的旧简化出发估算已改为引导查看正式红线，避免两个出发建议互相矛盾。
- 演示：[合成票据红线](http://127.0.0.1:3123/trips/11a87256-358b-479d-a571-8ad6f956a1a2)，当前V2。独立库 `test-data/phase15-live`；虚构班次11:35、接驳55分钟、安检20、站内步行10、缓冲20，建议09:45。不是实际购票或班次。
- `lib/redlines.ts`：纯确定性数据类型、逐截止倒推、正向步骤 / 截止检查、窗口判断、时间格式、颜色阈值。无模型、网络或内置当前时钟。日期用完整ISO时间；国内显示固定Asia/Shanghai，秒为耗时单位。
- `lib/redline-resolver.ts`：函数外的异步候选路线查询。入参时钟显式注入，候选上限3轮含首次；另从真实当前时间查一次。返回全部候选、所用路线、各截止结果及原因。
- `lib/redline-service.ts`：有效票据与计划转为输入，复用已存适用路线或安全降级。只有起点名称与票据起点一致的入站路线可代用。返程使用本票返程起点；前项结束晚于建议出发及多有效班次不一致均保留冲突。
- `lib/redline-preferences.ts`：偏好Schema和默认值。`app/components/redline-panel.tsx`：倒计时、明细、条件草稿、保存、校时 / 失效；总览 / 时间轴 / 交通组件接入。

## 数据与接口

无数据库迁移，仍为9个迁移。Ticket JSON新增可选 `redlinePreferences`，旧票据读取时派生默认值，不改历史。

字段：`baggage=unknown/none/checked`、`firstVisit`、`slowWalking`、`securitySeconds`、`gateWalkingSeconds`、`checkInSeconds`、`bagDropSeconds`、`extraBufferSeconds`、`minimumArrivalSeconds|null`。默认安检1200秒、站内步行600秒、值机和托运各900秒，额外缓冲继承原票 `bufferMinutes`；均为可调整个人估算。首次到访 / 慢步行 / 大件行李各加300秒，并显示原因。

- `GET /api/trips/:id/plans/:version/redlines`：经过应用访问校验，无缓存，返回 `{planId,isCurrent,serverNow,redlines}`。派生结果包含输入依据、算法 / 计划身份、计算时刻、建议、必要耗时、缓冲、来源精度、每轮候选、建议与当前两条正向检查、冲突。
- `POST .../tickets` 新增 `{action:"update_redline",ticketId,preferences}`。复用版本事务、访问 / CSRF校验、只允许有效票；旧版409。新PlanVersion保留事件、路线、成本和旧requestSnapshot/R，不给未确认新需求补新修订。同步票据的额外缓冲分钟字段；其他票面补充入口同步回偏好，避免两个编辑入口数值分叉。
- 偏好修改不破坏原始路线；新计划ID立即使旧红线失效。改票、起点、接驳和路线沿用旧阶段版本 / 路线失效规则。`draft/cancelled/replaced`不生成硬约束红线。
- 红线结果不存成永久有效记录。计算版本为`redline-15.1:<planId>`，`calculatedAt`区分重新检查时钟。每次按当前快照派生，防止新票 / 新路线混用旧结果。历史只读。

## 算法与边界

必要耗时只汇总一次接驳总耗时及到相应截止点的办理步骤。接驳分项只展开；只有完整分项之和等于总项时展示连续分段时刻，不重复加总。机动缓冲与流程办理分开；每个截止倒推后取最早建议，不累加多个截止的缓冲。“至少提前到站”变成进站口截止参与比较。

固定路线直接倒推并正向检查。有时刻依赖的路线先用参考耗时产生候选，再对候选调用lookup，严格核原始完整日期 / 适用窗口与所有截止；不把旧候车时间标成新查询。可接收提供方的其他候选，也能按返回耗时保守重算；成功仅代表所列候选通过，不声称全局最晚。循环、查询失败、不适用或3轮结束均待确认。失败调用也计一轮。

路线缓存复用阶段13的`routeCacheKey/readCachedRoute/writeCachedRoute`；完整日期、出发时刻（含秒）、方式、坐标及计划 / 路线身份均进入口径，读到后仍检查窗口。人工记录不进入共享缓存。当前既有提供方不保证自动未来公交 / 驾车查询，适用资料不足时立即降级；本阶段没有新增抓取或付费服务。某时刻无运营，只能约束该时刻窗口，不能跨时刻推断无运营。

航空分别建立值机、托运、安检步骤和登机截止；无托运不加托运。票面未提供办理截止不当零，高铁可按发车前5分钟作可见假定，仍标估算；航空未知保持待确认。手工录入的截止也标假定，不能冒充官方已核验。

正向到达=截止是零余量，不能判安全。距建议超过15分钟绿色，大于0且不超过15分钟橙色，到时 / 过时红色；文字另外显示来源精度与可行性。倒计时读取当前时钟；前台focus / visibilitychange重新校准，正常30秒重查。与本机服务器偏差超过2分钟提醒时间不可靠；断网按设备时间显示并清除不能确认的结果。
