## 数据、接口和状态约定

### EvidenceFact

`EvidenceFact` 绑定 `tripId`、`planVersionId`、`targetType`、`targetId` 和 `field`。唯一键为 `[planVersionId, targetType, targetId, field]`。当前 `targetType` 固定为 `event`，`targetId` 是事件 ID；字段只能是：

- `opening_hours`：开放时间
- `reservation`：预约要求
- `price`：价格
- `location`：位置

重要字段：

- `status`：存储状态，只有 `verified`、`unverified`、`conflict`。
- `sourceTitle` / `sourceUrl` / `sourcePublisher`：实际读取或候选来源信息。
- `sourcePublishedAt` / `sourceDateStatus`：来源内容日期与适用判断。
- `extractedValue`：程序从正文提取的字段值，例如 `9:00—17:00`。
- `searchProvider` / `searchQuery`：搜索提供方与查询词。
- `retrievedAt`：实际读取时间。
- `applicableFrom` / `applicableUntil`：适用起止；当前截止为事件日期前一天本地零点。
- `lastRefreshAt` / `lastRefreshStatus` / `lastRefreshError`：最近刷新记录。
- `contentQuote`：纯文本正文摘录。
- `conflictReason`：待确认或冲突原因。

界面有效状态由 `effectiveEvidenceStatus` 计算：

- `verified`：已核验。
- `pending`：建议确认。
- `conflict`：来源冲突。
- `stale`：已过期/需复核；包括 `applicableUntil` 已过或最近刷新失败。

### 核验规则

1. 搜索结果只用于发现来源，不作为证据正文。
2. 必须提供官方域名，例如 `hnmuseum.com`；只有 URL host 等于官方域名或为其子域名时才继续读取。
3. 必须实际读取 HTML/plain text 正文并提取到字段值，才保存 `verified`。
4. 来源发布日期早于行程超过一年或晚于行程日期时保存 `unverified`。
5. 同一官方域名下多个页面提取值不同，或刷新结果与原 `extractedValue` 不同时保存 `conflict`。
6. 页面读取失败时，如果已有 EvidenceFact，则保留原来源和摘录，记录刷新失败并显示 `stale`；没有旧证据时不创建假核验记录。
7. 搜索无官方结果、页面无字段内容或读取失败时保持待确认，并提供可打开的候选/官方入口。
8. 官方页面未标注内容日期时记录 `undated`；仍可按读取时间核验当前常设页面，但到期前必须复核，不宣称永久有效。

### API

来源核验接口：

- `POST /api/trips/[id]/plans/[versionNumber]/evidence`
- Body：`{ eventId, field, query, officialHost }`
- 返回：`{ fact }`
- 只允许当前计划版本；历史版本返回 409。
- 常见错误：请求格式 400、计划/事件冲突 409、来源读取失败 502。

设置接口：

- `POST /api/settings/search/test`：测试当前 DuckDuckGo 搜索配置，返回一次性签名 `testToken`。
- `POST /api/settings/search`：必须携带有效 `testToken` 才保存；受个人密码会话和 CSRF 保护。

### 计划版本继承

- 普通日程编辑和费用编辑生成 V+1 时，复制仍存在事件的 EvidenceFact。
- 被移除事件的 EvidenceFact 不复制到新版本。
- 历史版本的 EvidenceFact 只读。
- EvidenceFact 不改写事件 `status` 或费用 `certainty/paymentStatus`；用户确认、AI 估算与外部核验仍分开显示。

## 搜索与安全边界

- 提供方：DuckDuckGo HTML 搜索，无需 Key。
- 语言：`en` 使用 `kl=us-en`，`zh-CN` 使用 `kl=cn-zh`。
- 页面读取限制：
  - 仅 HTTPS/HTTP。
  - 禁止 URL 凭证。
  - 仅允许 80/443 端口。
  - 禁止 localhost、`.local`、`.internal`、私网 IPv4 和常见私网 IPv6 解析结果。
  - 手动跟随重定向，最多 3 次，每次重新校验目标。
  - 请求超时 10 秒。
  - 响应体最多 512KB。
  - 仅读取 `text/html` 或 `text/plain`。
- 外部 HTML 会剥离 script/style/noscript，正文和摘录按纯文本渲染；没有 `dangerouslySetInnerHTML`。
- 外部内容中的指令不会改变系统规则、权限、数据库或密钥处理。
- 设置读取、测试和保存接口不返回或接受 DuckDuckGo Key；本提供方无需 Key。
