PATCH 请求格式：

    {
      fromEventId, toEventId, departureTime,
      manualReference: {
        availability: "available" | "no_service",
        instructions, durationMinutes: number | null,
        fareCents: number | null, sourceName, sourceUrl: string | null,
        checkedAt: ISO_UTC, acknowledged: true
      }
    }

返回 { plan }，仍生成唯一新的当前 PlanVersion。日期从当前版本起点事件获取；需同日、正向相邻且两个地点已确认，出发不早于上一项完整结束时间。非法输入 400、旧版本 409、跨源写入 403。事务内再核版本与事件关系；取消不写入。

## 数据与失效约定

RouteLeg 新增可选 manualReference，旧 JSON 没有该字段也可读取。保存的 manualReference 包含请求字段（不含 acknowledged），以及 date、departureTime、requiresReconfirmation。查阅时间 checkedAt 与服务端保存时间 retrievedAt 不混用。

distanceMeters、durationSeconds、arrivalDate、arrivalTime 现可为 null。available 可留空耗时或票价；no_service 强制耗时和票价为空，状态 unavailable。人工可用参考状态 pending_confirmation、futureQueryCapability=false、candidateRecheck.status=not_applicable；polyline=[]。步骤来自人工多行文字，不伪造线路 ID、具体班次、分段耗时或距离。

总耗时默认包括 walking/waiting/riding/transfer，不重复相加。到达使用原日期+出发+总耗时计算，仅参考；空耗时不计算到达或冲突。人工费用以分保存，按 per_person 乘人数一次；已有 local_transport 事件承担费用时不重复新增路线费。同一段重新记录只替换其派生费用。保留用户已确认费用和已支付事实，勿自动清零。

修改相关事件/地点使原参考 requiresReconfirmation=true、派生时刻/耗时/金额未知；原 manualReference 内容保留供核对。不再相邻或删除的路线从当前版移出，历史版保留；其未确认未支付派生费移除，已付/已确认费用保留并备注原路线失效。当前界面改出发时刻会清除确认勾选、保留未保存输入；必须再勾选才可提交，未保存选择不改计划。

自动缓存按完整日期、时刻、方式、provider、坐标区分。人工不复用它。T28 使用演示班次验证 08:45→09:30 / 09:05→10:30，不能当现实公交数据。自动候选最多 3 轮（含首次），没有未来查询能力就降级且不假称收敛；按实际调用次数记轮数。可选高德公交 futureQueryCapability 已收紧为 false，不再自动 verified；其真实服务仍未验证。
