结论：**外部条件待验收**。完整证据见[阶段 13 验收](../阶段验收/阶段-13.md)。

## 实际交付

- 相邻已确认地点可查询步行、公交、驾车路线。
- 步行/驾车走 OSRM，保存真实折线、步骤、距离、耗时、费用依据和适用时刻。
- 公交在免费 OSM 方案下明确降级，不画伪路线；高德适配已实现，但未配置 Key。
- 路线缓存按完整日期、出发时刻、交通方式和地点坐标隔离，T28 两次查询不互相污染。
- 候选复核最多 3 轮；不收敛或缺少未来能力时降级为“待确认”。
- 路线保存为新的 `PlanVersion.routeLegs`，历史版本保留。
- 时间轴显示交通行、冲突和到达时刻；地图显示路线箭头。

## 主要文件

- `lib/routes.ts`：路线 schema、缓存、OSRM/高德解析、T28、候选复核。
- `lib/route-service.ts`：路线查询、外部服务调用、降级和保存。
- `lib/plan-service.ts`：路线持久化、费用归属、失效与版本保护。
- `app/components/plan-map.tsx`：路线查询表单、路线卡片和地图入口。
- `app/components/plan-timeline.tsx`：交通行、冲突和到达时刻。
- `app/components/map-canvas.tsx`、`app/map/frame/map-frame.tsx`：折线和方向箭头渲染。
- `app/api/trips/[id]/plans/[versionNumber]/routes/route.ts`：路线查询 API。
- `prisma/schema.prisma`、`prisma/migrations/20261011090000_add_plan_route_legs/`：`routeLegs` 字段。

## 数据约定

- `RouteLeg` 保存：
  - `date`、`departureTime`、`validFromTime`、`validUntilTime`
  - `arrivalDate`、`arrivalTime`
  - `mode`、`status`、`distanceMeters`、`durationSeconds`
  - `includedTimes`、`polyline`、`coordinateSystem`
  - `steps`、`futureQueryCapability`
  - `candidateRecheck`、`scheduleBasis`、`cost`
  - `cacheKey`、`source`、`retrievedAt`、`conflict`
- `includedTimes` 记录步行、候车、换乘、驾车、乘车，避免重复计时。
- `candidateRecheck` 记录轮数、请求时刻、最终时刻和收敛状态。
- `routeLegs` 保存在 `PlanVersion.routeLegs` JSON 中，默认 `[]`。

## 路线缓存与复核

- 缓存键包含完整日期、出发时刻、交通方式和地点坐标。
- 08:45 与 09:05 不会互相命中。
- 最多复核 3 轮。
- 缺少未来查询能力或复核不收敛时，状态为 `pending_confirmation`。

## 费用归属

- 公交按人计。
- 驾车按次计。
- 步行无车费。
- 已关联 `local_transport` 事件时不重复添加路线费用。
- 费用未知时进入预算“待确认”，不写成 0 元。
