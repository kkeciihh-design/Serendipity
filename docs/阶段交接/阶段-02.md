## 数据目录、当前数据结构版本、必要迁移与备份

- 本阶段未创建数据库或业务数据目录。
- 草稿数据结构在组件内为 `{ id, text, updatedAt }`，其中 `id` 为临时 `draft-*` 标识，`text` 为用户原话，`updatedAt` 为浏览器端提交时间。
- 没有数据结构版本、迁移或业务备份。
- 刷新页面会清空草稿，这是阶段 02 的明确边界，不是可恢复数据。

## 本阶段新增或改变的数据/接口约定

- 输入上限按 Unicode 码点计数，最大 3000 字；超过上限时保留输入内容并阻止提交。
- 空白、纯空格或纯换行不能提交，但输入内容不被清空。
- Enter 提交，Shift + Enter 换行；`nativeEvent.isComposing` 为 true 时忽略 Enter，防止输入法选词误提交。
- 提交期间用状态与 ref 双重防重复；快速双击只保留一版当前草稿。
- 未新增 HTTP 接口、服务端函数、数据库表、AI 适配器、地图模块或登录模块。
