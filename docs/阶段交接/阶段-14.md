## Ticket 与接口协议

`id` 是稳定票据 ID；`status` 为 `draft / active / cancelled / replaced`。`confirmedAt` 记录曾确认事实，退票/替换和补资料不抹去它；`cancelledAt`、`replacedAt` 记录状态时间，替换旧票以 `replacedByTicketId` 指向新票。同班次同行票不会自动合并，不采集姓名/证件。

POST 请求为下列动作之一：

- `create_draft { ticket }`：存草稿，不改变当前交通约束、路线或预算。
- `activate { ticket, acknowledged: true }`：新增用户已核对的有效票。
- `activate_draft { ticketId, acknowledged: true }`：原草稿 ID 生效。
- `update_details { ticketId, ticket, acknowledged: true }`：草稿可编辑；有效票可补原来缺失的关键字段和调整接驳/办理参考，已有非空票面关键字段不能改写，需要使用指定替换。保留 ID 与初次确认时间。
- `cancel { ticketId, acknowledged: true }`：记录用户已办妥指定票退票。
- `replace { ticketId, replacement, acknowledged: true }`：一次提交将指定旧票设 replaced、新票设 active；新旧票方向和主交通事件必须一致。

响应为 `{ plan }`，含当前版本对应的 evidenceFacts。历史/过期版本写入返回冲突；所有动作失败保留原版本。页面的勾选随输入改变失效，取消操作不发保存；切换方向或收起面板保留未保存输入。

所有日期时刻按 Asia/Shanghai；日期使用完整年月日。金额为整数分、接驳输入为分钟。`fareCents` 是每人票价，乘 `passengerCount`；`accessFareCents / egressFareCents` 是全段总价，不再乘人数。同段同行接驳按事件/方向/日期/时刻/具体端点/方式共享一次。

## 事实、约束与路线

只有 `status=active` 且存在 `confirmedAt` 的票据参与当前约束。票面资料不足、到达矛盾、超出现有单项 24 小时能力、不同同行班次无法放进单线行程时，仍保存真实字段并显示待补/冲突，绝不挪动票面以制造可行。事件的 `ticketTimingPending` 防止把旧占位时刻显示成已核对票面。

同一事件仍有有效同行票时保留约束；最后一张停用后解除票据约束。票据管理事件不能在普通时间轴编辑中解锁或改变关键内容。已确认票据（含退票/替换历史）也受既有重新生成保护，当前基础生成不会丢掉其历史；完整保留约束的重规划留待阶段 22。

有效票变化使相关城市路线的耗时、到达、折线等派生内容失效并待重算。跨城市只展示站点关系示意，不构造实时轨迹。不同站点/航站楼不得复用旧地点坐标。同名机场换航站楼也会清除旧定位。

保存票据本身不依赖外部路线成功；事务内不请求外部服务。资料缺失或离线照样原子保存票据、费用和失效状态。事务核对当前 PlanVersion；新版本沿用其 `requestSnapshot / requestRevision` 和 `requirementUpToDate`。用户改需求但尚未确认时，事实仍可保存，计划继续待更新。

## 费用规则

草稿不入预算。每张已确认票具有独立费用身份；未知金额保持未知。已有票费的付款状态、预算修订和退款后净额不会被后续票据更新重置。退票/替换保留已发生金额；用户在阶段 09 预算入口另行确认退款及净额，不自动归零。

若主交通原来已经有阶段 09 确认/支付的基础费用，首次票面沿用原费用 ID 与证据，避免把同一付款再加一次；其后同行或替换票各自记账。接驳已有受保护城市路线费用时保留该行，金额差异提示用户在预算核对。旧的未知路线占位可由新人工接驳参考替代；票据与路线引用同一接驳时不叠加预算。

## 时刻与能力边界

门到门链显式包含起点、前段接驳、进站/机场办理、主交通、出站/取行李、后段接驳和终点；返程终点为最终返回点。接驳总耗时包含步行、等待、换乘；后段含出站/取行李，不再重复叠加。

航空值机、托运、登机截止分别保存，取所填规定中最严格者，额外安全余量只加一次。不适用项可明确填 0 并备注；缺办理截止则保留待确认，不能把未知当 0。高铁检票截止同样待核对。默认 30 分钟余量是可修改建议值。

当前计算只是人工资料的参考时刻和相邻事项衔接检查，不是阶段 15 正式红线。公交/地铁末班及未来等待需在官方平台按实际日期时刻核对；备注可记录停运/末班事实，但本阶段没有自动班表或末班推导。驾车燃油/路桥/停车金额未知时不会按零算。

没有准确票面时，只展示计划预留候选时段和 12306/航旅纵横入口。两个链接实测 HTTP 200，但没有验证实际余票、价格、航班运行、航空办理规则或自动公交接口。没有 OCR、自动购票/退票/改签、多人分路、付费 API、远程部署。
