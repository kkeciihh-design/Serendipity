## 本阶段新增或改变的数据/接口约定

- `GET /api/trips`：返回 `{ trips: Trip[] }`，按 `updatedAt` 倒序。
- `POST /api/trips`：请求 `{ originalRequest: string }`，成功返回 HTTP 201 和 `{ trip: Trip }`。
- `GET /api/trips/:id`：存在返回 `{ trip }`；不存在返回 HTTP 404。
- `PATCH /api/trips/:id`：可提交 `title` 和/或 `originalRequest`，成功返回 `{ trip }`。
- `DELETE /api/trips/:id`：成功返回 `{ deleted: true }`；不存在返回 HTTP 404。
- API 错误统一返回 JSON `{ error: string }`；校验失败为 400，未找到为 404，数据库读写失败为 5xx。
- 原话按 Unicode 码点计数，非空且最多 3000 字；标题会 trim，非空且最多 80 字；原话本身不 trim，以保留用户输入。
- 自动标题取第一行非空文本，超过 30 个 Unicode 码点时截断并追加省略号；用户可在详情页改名。
- API JSON 中的时间为 ISO 字符串；服务端 Prisma 类型使用 Date。
- 页面直接调用服务端函数读取列表和详情，浏览器组件通过 API 修改与删除。
- 删除必须输入当前已保存标题的完整名称才启用确认按钮。
