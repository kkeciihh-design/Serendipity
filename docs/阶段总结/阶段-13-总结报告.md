## 现在可以怎样使用

正式入口：[打开我的旅行](http://127.0.0.1:3003/trips)。

打开已有旅行，在“地图”页确认相邻两个地点后：

1. 将交通方式选为“地铁/公交”，选择出发时刻。
2. 点击“在高德查看公交路线”。系统会带着起终点打开高德，无需在本项目配置 API Key。
3. 在外部地图核对日期、时刻和运营情况，回到本项目填写线路、上下车站和换乘步骤。
4. 填写包含步行、候车、乘车、换乘的总耗时及每人票价；不知道的数字可以留空。记录来源和查阅时间，勾选核对确认后保存。
5. 地图页和时间轴会显示人工参考、预计到达及已有日程冲突，预算按人数计入一次。查看不到公交或已停运时，可保存“无路线／停运”记录。

可直接查看：[人工公交演示](http://127.0.0.1:3121/trips/c2a71289-cced-46c6-b274-f245a3198fda)。此处的线路、55 分钟和 6.50 元均为标明用途的测试数据，不是深圳公交班次或报价。

## 已完成的功能

- 无需 Key 的高德外部公交入口，正确转换坐标、编码地点名称；链接只传两个地点，不传旅行 ID 或项目密钥。
- 人工保存线路、换乘、总耗时、每人票价、来源、来源网址、查阅时间及适用日期/时刻。
- 可用参考与无路线/停运记录分开；耗时、距离、到达时间和费用未知时保持未知，不虚构数字或地图道路。
- 保存生成新计划版本；历史版本只读，刷新和重启后记录保留。
- 修改出发时刻清除核对勾选，同时保留尚未保存的输入；旧记录清楚标明不适用于新选择。
- 修改日程或地点使相应参考失效；日程重排后移除不再相邻的旧路线，保留历史记录和已确认/已支付费用。
- 保留并复查真实步行/驾车路线、地图方向箭头和时间轴联动。
- 收紧原有高德自动适配的能力声明，不再因提交了日期参数就宣称已验证未来班次。

## 明确保留的限制

人工记录始终显示“人工参考／待确认”，确认勾选不等于系统验证了实际运营。外部链接不能自动设置出行日期和时刻，也不会自动把方案回传；用户需根据外部地图实际提供的能力自行查阅。本次高德网页出现了登录提示，未进行登录或注册。

没有接入付费公交 API，也没有实现自动未来班次、实时到站或精确候车计算。后续如引用这些人工耗时，只能作为估算；更改日期或时刻必须重新核实。人工公交不绘制虚构折线，真实步行和驾车仍由现有服务提供。
