## 4. 本阶段详细规格

### 目标

生成可保存到手机相册的清晰竖版旅行图。

### 用户能看到什么

完整长图预览；内容过长时得到按天或段落拆分的多张图。

### 功能要求

显示必要时间轴、地图、红线、预算与注意项；图片/字体加载完成后生成；长内容不截断，展示文件数量。

### 页面

长图预览、生成状态与下载。

### 交互

选择日期和内容 → 生成 → 看预览 → 保存图片；失败可重试，重复点击不并发堆积任务。

### 数据

固定快照、许可允许的图片/地图资源、文件记录和分段信息。

### 技术实现

AI 安装受控 Chromium 运行依赖；用专用导出 HTML 渲染截图，限制资源访问、尺寸、并发和超时。

### 测试

2 天单张、4 天分段、中文字体、长名称、图片失效、地图授权/加载失败、文件尺寸与敏感信息检查。

### 验收标准

实图可读、首尾完整、分段不丢事件；地图/红线/数值与快照一致；无空白却报成功。

### 常见失败情况

超过浏览器最大图高、中文缺字、资源未加载就截、生成后占用不释放。

### Definition of Done

通用 DoD 通过，AI 打开并检查所有生成图片，资源和并发异常有测试。

### 本阶段不做什么

不同时实现 PDF，不做复杂在线海报编辑器。

## 5. 按这个顺序完成

1. 核对已验证的地图/图片导出许可，准备受控的竖版渲染页面。
