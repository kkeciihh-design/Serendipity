## 4. 本阶段详细规格

### 目标

生成可以保存和打印的完整私人旅行手册。

### 用户能看到什么

含封面、每日安排、地图、推荐、预算、清单和来源的多页 PDF。

### 功能要求

满足第 20.5 章全部内容；中文嵌入字体、合理分页、地图署名、可读编号；跨城图与当地详图不相互挤压。

### 页面

PDF 内容选择、预览和下载。

### 交互

选择完整手册、确认隐私选项、生成并预览；关键资源缺失清楚失败，不静默生成缺页版。

### 数据

复用同一快照和已授权资源，增加 PDF 文件与版本记录。

### 技术实现

复用 Chromium，新增打印样式和页眉/页码；导出仅允许受控页面与资源，不提供任意网址截图服务。

### 测试

2/4 天、长卡片、跨日、多页清单/来源、缺字体/地图、生成中计划变化；抽取文本并逐页渲染检查。

### 验收标准

必需章节全部存在，内容/编号/红线/预算一致，所有页面中文可读、无截断、地图真实可见。

### 常见失败情况

只有封面和攻略文字、卡片跨页断裂、字体缺失、地图空白、只检查第一页。

### Definition of Done

通用 DoD 通过，实际 PDF 及全部页图经 AI 检查；T21/T27 相关项通过。

### 本阶段不做什么

不做可交互 PDF、复杂出版排版或生成新旅行内容。

## 5. 按这个顺序完成

1. 基于同一快照建立打印布局，内置允许分发的中文字体与页码。
2. 加入封面、总览、每日时间轴/地图、三类推荐、预算、清单、提醒和来源。
3. 处理分页、长卡片、跨城概览与城市详图，保留必要地图署名。
4. 生成2天/4天PDF，抽取文本核对，再逐页渲染检查所有页面。
5. 运行下面的验收项，发现失败自行修复并复测；保存实际结果，不复制预期冒充已通过。
6. 更新开发进度、本阶段验收和交接文件，向用户提供入口与结论，然后停止。
