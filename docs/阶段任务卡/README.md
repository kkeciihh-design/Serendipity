# 分阶段开发任务卡

你每次只需要一张卡：**同一项目，新开窗口，按顺序做；上一阶段通过后再交下一张。**

当前应用尚未开发。下面31张卡是待执行任务，不是31个已完成阶段。

先读[使用说明](使用说明.md)，然后从[阶段 00：项目骨架](阶段-00-项目骨架.md)开始。每张卡开头都有无需填写变量的复制指令。

- 所有窗口使用项目目录 C:/Users/11295/Desktop/Serendipity。
- 新 Agent 会自行读取[开发进度](../开发进度.md)、[执行规则](../AI-Coding-执行总规则.md)和前一阶段交接。
- 任务卡编制时只完成了文档拆解，没有初始化应用或执行任何产品测试；后续真实进度由开发 Agent 记录。
- 不要同时把不同阶段发给多个窗口；你无需自己运行测试或手工整理技术交接。

## 完成一次之后

Agent 判定“通过”并写好验收与交接后，你新开窗口发下一张。判定“不通过”或“外部条件待验收”时，继续当前卡，不需要你检查代码。你也可以把该 Agent 的阶段报告发回这个文档规划窗口，用于修订下一张卡。

任务卡依据当前蓝图生成。若前一阶段实际方案发生必要变化，下一 Agent 应核对项目事实并记录调整，不能照旧卡重建项目或改变已经确认的范围。
