# Serendipity 使用说明

当前是本机运行版本。阶段30的代码修复和本机回归已完成，整版结论仍为**外部条件待验收**：自动来源查询遇到搜索服务人机验证，手机真机打开离线HTML尚未验证。完整结果见[阶段30验收](阶段验收/阶段-30.md)。

## 打开和关闭

打开桌面“Serendipity 日常使用”文件夹，双击“启动旅行助手”。网页会自动打开；重复点击会复用当前应用。当前入口是[我的旅行](http://127.0.0.1:3003/trips)，地址变化时以启动器打开的网页为准。

保存编辑后，双击“停止旅行助手”即可关闭后台。只关浏览器不会停止应用。电脑重启后再双击启动；遇到问题可打开“运行状态”。

## 规划一趟旅行

1. 在首页描述出发地、目的地、日期、人数、预算和兴趣。应用支持2～4天；不确定的项目可以留待追问。
2. 核对AI整理的需求，保存并确认，再生成计划。计划保存后可以从“我的旅行”重开。
3. 在时间轴调整活动；到地图选择准确地点，再查询相邻路线。预算中的估算、未知费用和已支付金额含义不同。
4. 已买高铁票时导入截图，逐项核对日期、车站、车次、时刻和金额后确认。识别草稿不会自动成为有效票；退改签须先在购票平台办理，再更新本工具记录。
5. 查看时间红线及其假设。出现冲突或“待确认”时先核对票面、接驳和相邻安排；它不代表已保证赶得上车。
6. 下雨、晚起或想删掉景点时，使用“AI重新规划”，看完变化再应用。新需求与旧计划不一致时，先确认新需求。

## 出发和随身资料

在“出发前清单”记录准备进度，在“行程提醒”查看天气及相关事项。来源未核验时会明确提示；搜索失败不会自动变成已核验。预约、房态和现场排队还需按实际情况确认。

“旅行执行模式”支持手动开始、到达、完成和选择当前步骤。拒绝定位后仍能手动使用；手动完成只是自己的记录。

出发前从计划或执行页生成并保存：

- **手机一页版HTML**：独立静态资料；Windows Edge断网阅读已验证，Android/iOS实际文件打开方式待验收。
- **文字**：可复制全文，或下载TXT/Markdown；复制失败时仍可全选或下载。
- **旅行长图**：适合相册查看；有多张时全部保存。
- **PDF旅行手册**：按页阅读，含计划已有的公开地点示意、许可照片、预算、清单和来源。地图为位置示意，不用于道路导航。

文件保留生成时的计划和进度，修改旅行后需要重新生成。默认隐藏私人地址和座位，分享前核对隐私选项。本机网址只能在这台电脑打开，电脑关机或休眠时不可达；尚无个人外网实例，离线文件不能在线重规划。

## 备份与恢复

进入“个人设置 → 数据管理”，下载JSON旅行备份。备份包含旅行及历史、必要票据字段、费用、清单和执行记录，不包含服务密钥、登录状态和票据原图。

恢复会替换当前全部旅行。先下载当前备份，再选择要恢复的文件，核对预览后确认；恢复完重新载入页面。更换电脑后需在设置页重新填写服务配置，两个实例不会自动同步。

数据保存在 `C:/Users/11295/AppData/Local/Serendipity`。保留该目录和桌面项目目录；不要通过删除数据库或替换旧数据库文件处理故障。
